# PC 견적 비교: Claude Code로 부품 최저가 찾고 견적 배포하기

**웹페이지:** https://bluerose219.github.io/pc-build-quote/

예산 100~200만 원(모니터 포함), 인텔 CPU, 개발·로컬 AI·사무/인강 용도로 PC 견적 3종을 짜서 웹페이지로 배포한 과정을 정리한 강의 노트입니다. 가격은 2026-10-13 다나와 기준입니다.

## 강의 내용

### 1강. 계획 세우고 폴더 구조 만들기

**요청:** "새 컴퓨터를 맞출 건데 부품 최저가 검색 및 조립 꿀조합으로 하고 싶어. 계획을 먼저 짜고 폴더 구조 정리해줘"

작업을 6단계로 나누고 단계마다 폴더를 만들었습니다.

```
01_요구사항/    예산·용도 정리
02_부품조사/    부품별 후보와 핵심 스펙
03_가격비교/    쇼핑몰별 가격 기록 (CSV)
04_견적조합/    견적서 + 호환성 체크
05_구매기록/    주문번호·보증기간
06_조립가이드/  조립 순서 체크리스트
scripts/        가격 조회 자동화
```

**배운 점**
- 바로 견적을 뽑기보다 요구사항 → 조사 → 가격 비교 → 조합 → 구매 → 조립 순서로 쪼개면 중간 결과를 파일로 남길 수 있습니다.
- CSV를 엑셀에서 한글이 깨지지 않게 열려면 UTF-8 BOM을 붙여 저장합니다.

### 2강. 외부 스킬을 프로젝트 범위로 설치하기

**요청:** "k-skill README에 있는 쇼핑몰 스킬들만 내 프로젝트 스코프로 설치해줘"

[NomaDamas/k-skill](https://github.com/NomaDamas/k-skill)의 🛒 쇼핑·중고거래 스킬 12개를 이 프로젝트에만 설치했습니다.

```bash
# -g(전역)를 빼면 프로젝트 범위(.claude/skills/)에 설치됩니다
npx --yes skills add NomaDamas/k-skill -a claude-code --copy -y \
  -s danawa-price-search -s naver-shopping-search -s coupang-product-search ...
```

**배운 점**
- `-g` 옵션 유무로 전역 설치와 프로젝트 설치가 갈립니다.
- 이 스킬들은 실행할 때마다 npm 패키지(`@nomadamas/k-skill`)에서 최신 안내문을 받아오는 구조라, 설치 후에도 동작이 바뀔 수 있습니다. 설치 전에 SKILL.md를 읽어 보는 습관이 필요합니다.
- 다나와 스킬은 파이썬 `beautifulsoup4`가 필요해서, 전역 환경을 건드리지 않도록 프로젝트 안에 `.venv` 가상환경을 만들어 설치했습니다.
- 윈도우에서 파이썬 출력 한글이 깨지면 `PYTHONIOENCODING=utf-8`을 설정합니다.

### 3강. 다나와로 최저가 조회하고 견적 짜기

**요청:** "견적 짜줘. 모니터 포함이고 인텔로"

다나와 스킬의 `search`(상품 후보 찾기)와 `offers`(판매처별 가격) 명령으로 부품마다 최대 40개 판매처를 비교했습니다.

```bash
scripts/danawa.sh search "RTX 5060 Ti 16GB"   # 후보와 pcode 찾기
scripts/danawa.sh offers 101725832 40          # 판매처별 실구매가
```

**배운 점**
- 최저가 1위는 대부분 **현금결제 전용가**입니다. 카드로 살 수 있는 최저가를 따로 봐야 비교가 정확합니다.
- 판매처가 한 곳뿐인 상품(처음 고른 GeIL RAM)은 품절·신뢰도 위험이 있어, 판매처가 많은 제품(Crucial)으로 바꿨습니다.
- 2026년에는 메모리 가격이 크게 올라 RAM 32GB가 64만 원 이상입니다. 예산 배분이 예전 공식과 다르게 나옵니다.
- 로컬 AI는 그래픽카드 VRAM이 가장 중요합니다. RTX 5070 Ti도 VRAM이 16GB라서 5060 Ti 16GB가 가성비가 더 좋습니다.

### 4강. 네이버·쿠팡 비교와 실패 처리

**요청:** "네이버와 쿠팡도 포함해서 가성비 좋은 걸로"

네이버쇼핑·쿠팡 스킬은 k-skill 프록시 서버를 거치는데, 조회 시점에 서버 쪽 오류로 결과를 받지 못했습니다.

| 스킬 | 오류 | 원인 |
|---|---|---|
| 네이버쇼핑 | upstream 404 | 프록시가 호출하는 네이버 API 주소 오류 |
| 쿠팡 | upstream 403 | 프록시의 쿠팡 파트너스 키 거절 |

**배운 점**
- 파이썬 기본 User-Agent는 프록시에서 403으로 막혔고, `curl`로 보내야 실제 오류 내용을 볼 수 있었습니다.
- 우회하지 않고 다나와 판매처 목록(G마켓·옥션·11번가·SSG·롯데ON)으로 대신 비교했습니다. 실패 내역도 가격 기록에 남겼습니다.

### 5강. 웹페이지 만들고 GitHub Pages로 배포하기

**요청:** "웹페이지 만들고 github cli에 배포해줘"

견적 데이터를 담은 HTML 한 장을 만들고 GitHub CLI로 배포했습니다.

```bash
git init -b main && git add index.html && git commit -m "PC 견적 비교 페이지 추가"
gh repo create pc-build-quote --public --source=. --push
gh api -X POST repos/<계정>/pc-build-quote/pages -f "source[branch]=main" -f "source[path]=/"
```

**배운 점**
- 프로젝트 전체가 아니라 `site/` 폴더만 저장소로 만들어서 `.env` 같은 파일이 올라가지 않게 했습니다.
- 무료 계정에서 GitHub Pages를 쓰려면 저장소가 공개여야 합니다.
- 페이지 데이터는 `index.html`의 `PARTS`(부품)와 `BUILDS`(견적) 객체에 모여 있어서, 가격이 바뀌면 그 부분만 고치면 됩니다.

### 6강. 예산 바꿔서 다시 짜기

**요청:** "100-200으로 예산 가격 수정해서 다시 해줘"

예산 250~300만 원 견적을 100~200만 원 견적 3종으로 다시 짰습니다.

| 줄인 부분 | 이전 | 변경 | 이유 |
|---|---|---|---|
| RAM | 32GB | 16GB (8GB×2) | 32GB가 64만 원 이상 |
| 메인보드 | B860 | H810 | 7만 원 절약, 225/225F에 충분 |
| SSD | 1TB | 500GB | 약 11만 원 절약 |
| 모니터 | 27인치 QHD | 24인치 FHD 100Hz | 약 16만 원 절약 |

### 7강. Git 기록과 저장소 관리

- 같은 파일을 덮어써서 푸시하면 웹페이지에는 새 버전만 보이지만, **이전 버전은 GitHub 커밋 기록에 그대로 남습니다.** 공개 저장소라면 누구나 볼 수 있습니다.
- 기록까지 지우려면 커밋 기록을 정리한 뒤 강제 푸시를 하거나, 저장소를 삭제하고 새로 만들어야 합니다.
- 저장소 삭제는 `gh` 기본 로그인 권한에 없습니다. `gh auth refresh -h github.com -s delete_repo`로 권한을 따로 받아야 합니다.

## 살 때 주의할 점

- 현금 최저가는 대부분 소규모 컴퓨터 전문몰입니다. 판매처 평판을 확인하세요.
- 견적 3은 카드 일반결제 시 200만 원을 약 5만 원 넘습니다. 현금 구매나 카드 할인(SSG KB국민카드 등)을 쓰면 예산 안입니다.
- 가격은 조회 시점 기준이라 계속 바뀝니다. 네이버쇼핑·쿠팡은 비교에 포함되지 않았습니다.
