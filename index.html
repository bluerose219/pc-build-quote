이렇게 고른 이유

  • 그래픽카드 VRAM 16GB: 로컬 LLM은 VRAM이 가장 중요합니다. 5070 Ti(182만 원~)도 16GB라서 5060 Ti 16GB의 가성비가 가장 좋습니다.
  • RAM 32GB: 메모리 가격 폭등으로 64GB는 180만 원이 넘습니다. 슬롯 2개가 남으니 가격이 내려가면 늘리세요.
  • RAM 제품: 판매처가 40곳 이상인 Crucial로 골랐습니다.
  • CPU: 250K Plus(고성능 6 + 효율 12코어)는 개발 작업에 충분합니다. B안의 225F는 기본 쿨러가 있고 내장그래픽이 없습니다.
  • 파워 750W: 실제 소비전력은 400W 안팎이라 나중에 그래픽카드를 바꿀 여유가 있습니다.

호환성 체크

  • CPU 소켓 LGA1851 = B860 메인보드 소켓
  • 메인보드 BIOS가 250K Plus를 지원하는지 판매처에 확인
  • RAM·메인보드 모두 DDR5
  • 파워 750W ≥ 5060 Ti 권장 용량
  • mATX 보드 → 미들타워 케이스 장착 가능
  • 쿨러 높이(155mm) ↔ 케이스 지원 높이 확인
